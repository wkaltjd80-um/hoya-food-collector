# 🌐 Notion Web Collector (노션 웹 링크 수집 & 정리 웹앱)

웹서핑 중 저장하고 싶은 기사, 유튜브, 블로그, 쇼핑, 개발 레퍼런스 링크를 입력하면 **제목, 핵심 요약, 대표 이미지, 파비콘**을 자동으로 추출하여 내 노션 페이지/데이터베이스에 실시간으로 깔끔하게 정리해 주는 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 더블 클릭으로 바로 실행 (가장 간편)
프로젝트 폴더 내 **`start.bat`** 파일을 더블 클릭하면 서버가 실행되고 웹 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

### 방법 2. 터미널에서 실행
```bash
node server.js
```
실행 후 브라우저에서 `http://localhost:3000` 으로 접속하세요.

## ⭐️ 노션 실시간 연동 3단계 가이드

현재 기본 타겟 ID로 사용자님의 노션 페이지(`166ad860bd648097afedff31acfa1fb5`)가 설정되어 있습니다.  
노션 API를 통해 실제로 페이지에 저장되도록 하려면 다음 3단계를 진행해 주세요:

### 1단계: Notion API 키 발급
1. [Notion 통합 관리 페이지(https://www.notion.so/my-integrations)](https://www.notion.so/my-integrations) 로 이동합니다.
2. **`+ 새 통합 만들기`** 버튼을 클릭합니다.
3. 이름(예: `웹 링크 수집기`)을 입력하고 연결할 워크스페이스를 선택한 뒤 **저장**합니다.
4. 생성된 **`내부 통합 시크릿 (secret_... 또는 ntn_...)`** 토큰을 복사합니다.

### 2단계: 노션 페이지에 봇(통합) 권한 부여 (필수 ⭐️)
1. 저장할 노션 페이지([https://app.notion.com/p/166ad860bd648097afedff31acfa1fb5](https://app.notion.com/p/166ad860bd648097afedff31acfa1fb5))를 엽니다.
2. 페이지 우측 상단의 **`···` (더보기)** 아이콘을 클릭합니다.
3. 메뉴 맨 아래 **`연결(Connect)`** 또는 **`연결 추가`**를 클릭합니다.
4. 1단계에서 만든 **`웹 링크 수집기`**를 선택하여 추가합니다.

### 3단계: 웹앱 설정에 키 등록
1. 웹앱(`http://localhost:3000`) 상단 우측의 **`⚙️ 설정`** 버튼을 클릭합니다.
2. 1단계에서 복사한 **Notion API Secret Key**를 입력하고 **`설정 저장`**을 누릅니다.
3. **`🔌 연결 테스트`** 버튼을 눌러 성공 메시지가 뜨면 모든 준비가 완료됩니다!

## 💡 주요 기능

- ⚡️ **스마트 자동 메타데이터 추출**: URL만 넣으면 제목, 설명, 썸네일, 파비콘, 사이트 이름을 즉시 파싱
- 🏷️ **자동 카테고리 & 태그 추천**: 링크 유형(개발, 기사, 영상, 쇼핑, 아이디어 등)을 분석하여 카테고리 자동 선택
- 📝 **메모 및 맞춤 태그 추가**: 노션에 함께 기록할 한 줄 메모와 해시태그 추가
- 🎨 **데이터베이스 & 일반 페이지 모두 지원**: 대상이 노션 데이터베이스면 표 속성에 맞게 등록되고, 일반 페이지면 하위 페이지 및 북마크 카드로 저장됩니다.
- 📱 **모바일 & 데스크톱 완벽 반응형 UI**: 다크 모드, 글래스모피즘 기반의 세련된 디자인
- 📦 **0-Dependency 경량 서버**: 외부 무거운 패키지 없이 순수 Node.js 표준 라이브러리로 작동하여 파일 잠금이나 충돌 없이 안정적입니다.
