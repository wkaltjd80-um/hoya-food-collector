노션과 실시간으로 연동하려면 Notion 개발자 포털에서 발급한 내부 통합 시크릿 키가 필요합니다. 아직 키가 없으시더라도 로컬 대시보드 저장 기능으로 바로 사용해 보실 수 있습니다.

노션 링크(https://app.notion.com/p/...)의 32자리 고유 번호입니다.

노션 연동 3단계 완벽 가이드

1

Notion API 키 발급받기

1. Notion 개발자 포털 (내 통합) 로 이동합니다.

2. [+ 새 통합 만들기] 버튼을 클릭합니다.

3. 이름(예: 웹 링크 수집기)을 입력하고 워크스페이스를 선택한 후 저장합니다.

4. 생성된 '내부 통합 시크릿 (secret_... 또는 ntn_...)'을 복사합니다.

2

내 노션 페이지에 통합 봇 추가하기 (중요 ⭐️)

1. 연결할 노션 페이지(166ad860bd648097afedff31acfa1fb5)를 웹 브라우저나 노션 앱에서 엽니다.

2. 페이지 오른쪽 상단의 점 세 개 (···) 버튼을 클릭합니다.

3. 맨 아래 [연결(Connect)] 또는 [연결 추가]를 누릅니다.

4. 1단계에서 만든 '웹 링크 수집기'를 찾아 선택하고 확인을 누르면 권한 부여가 완료됩니다!

3

웹앱 설정에 키 등록하고 저장 시작하기

1. 이 웹앱 상단의 [⚙️ 설정] 버튼을 누릅니다.

2. 1단계에서 복사한 시크릿 키를 입력하고 [설정 저장]을 누릅니다.

3. 이제 웹 링크를 입력하고 [노션에 저장하기]를 누르면 끝!

대표 음식 / 식당 사진 선택

인터넷이나 블로그에서 음식 사진을 [우클릭 ➡️ 이미지 주소 복사]하여 붙여넣으실 수 있습니다.

아이폰 (Safari)
  1. 사파리로 위 주소 접속 후 하단 중앙 [공유 아이콘 ⎋] 터치
  2. 화면을 올려 [홈 화면에 추가] 터치
  3. 호야 캐릭터 아이콘 확인 후 [추가] 터치하면 바탕화면 설치 끝!
갤럭시 / 안드로이드 (Chrome)
  1. 크롬 브라우저로 접속 후 우측 상단 [점 세 개 (···)] 터치
  2. [홈 화면에 추가] 또는 [앱 설치] 터치
  3. 스마트폰 바탕화면에 귀여운 전용 앱 아이콘으로 자동 생성!
